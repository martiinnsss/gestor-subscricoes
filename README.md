# Gestor de Subscrições

Página web simples para controlar todas as subscrições (streaming, música, jogos, software, ginásio…) e saber exatamente quanto gastas por mês e por ano.

**Problema que resolve:** pequenas mensalidades somam-se sem darmos por isso, e muitas renovam sozinhas quando já nem as usamos. Aqui vês tudo num só sítio e és avisado antes de cada renovação.

🔗 **Experimenta online:** https://martiinnsss.github.io/gestor-subscricoes/

## Funcionalidades

- Adicionar, editar e apagar subscrições (nome, preço, periodicidade, data de renovação, categoria)
- **Total mensal e anual**, convertendo automaticamente subscrições anuais e semanais
- **Avisos de renovação** nos próximos 3 dias e destaque das que renovam nos próximos 7
- Datas de renovação que **avançam sozinhas** para o ciclo seguinte quando passam
- Gráfico de **gasto mensal por categoria**
- **Cópia de segurança**: exportar e importar os dados em JSON
- Funciona **offline**, sem instalar nada e sem criar conta — os dados ficam guardados no próprio browser
- Responsivo: funciona no computador e no telemóvel

## Como usar

Descarrega o projeto e abre o ficheiro `index.html` no browser. Mais nada.

> Os dados ficam no armazenamento local do browser (`localStorage`). Se limpares os dados de navegação perdes a lista — usa o botão **Guardar cópia de segurança** de vez em quando.

## Tecnologias

HTML · CSS · JavaScript (sem bibliotecas nem frameworks)
